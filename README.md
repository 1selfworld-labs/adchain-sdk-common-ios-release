# AdChain Common iOS

AdChain SSP SDK 공유 타입 패키지 (바이너리 배포).

## 포함 타입
- `AdchainSspBridgeProtocol`
- `SspAdCallback`
- `SspAdError`
- `SspAdType`

## 설치 (Swift Package Manager)

```swift
.package(url: "https://github.com/1selfworld-labs/adchain-sdk-common-ios-release.git", from: "0.2.0")
```

## 버전

현재 버전: v0.2.0

> 이 레포는 바이너리 배포용입니다. 소스는 별도 관리됩니다.
